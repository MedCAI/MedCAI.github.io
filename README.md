# Linghan Cai academic homepage

Static academic homepage for `https://medcai.github.io/`, designed for GitHub Pages.

## Preview

Run a local server from this directory:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Publish

Create the public repository `MedCAI/MedCAI.github.io`, commit these files to its
default branch, and enable GitHub Pages from that branch if GitHub does not do so
automatically.

The public site intentionally omits private resume fields such as phone number,
date of birth, hometown, and political affiliation.
